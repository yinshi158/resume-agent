# 0005. 幻觉检测三层分工 + attribution 保守默认 + formula 白名单求值

状态：已定稿
日期：2026-09-16

## 背景

"生成时声明出处"只解决"句子没有家"，不解决"借壳加料"（声明了出处但
内容超出条目信息）。量化改写是误报重灾区："70 万→91 万"写成"提升
30%"算不算幻觉，规则不定清楚检查器会误报泛滥。LLM 自评置信度校准
差，不能用。

## 决定

1. **L0 确定性实体比对**：数字/公司名/技能词用正则+词表抽取，改写稿
   实体 ⊆ 事实源实体 ∪ 合法衍生。不看声明出处。
2. **归因动词检查（确定性，先于 L2）**：attribution=team/mixed/unknown
   的条目不得搭配"主导/独立负责"等主导级动词；未确认前只许"参与"级。
   依据 verb_lexicon 词表（主导级/参与级，版本化持续维护资产）。
3. **L1 衍生数字校验**：衍生数字合法当且仅当可由事实源数值推导。
   改写器必须输出 formula（允许区间形式），校验器**重算**而非信声明；
   反推值须在原文精度内成立。模糊量化词（"近翻倍"）不得引入原文没有
   的，除非映射到区间且原文数值落区间内。
4. **L2 LLM 蕴含判定**：只核对"声明的出处是否蕴含这句话"，输出
   句子→条目 ID 映射，映射不上标红。
5. formula 求值**禁用 eval**：白名单 AST（只允许数字、四则运算、
   括号、百分号字面量），其余节点类型一律拒绝。
6. 置信度用可计算异象信号（日期倒序/重叠、日期格式歧义、百分比超界、
   金额量级突变、schema 缺字段），不用 LLM 自评。

## 后果

- 正面：三层按实体类型分工（偷渡数字归 L0/L1，团队成果配主导动词归
  词表检查，定性表述借壳归 L2），LLM 只承担最窄的语义判定。
- 负面：verb_lexicon 是长期维护负担；formula 白名单表达力有限，
  复杂推导会被拒（可接受——拒了走人工）。
- 不可逆性：决定事实源与改写输出的 schema（entities、derived、
  source_fact_ids 字段），是数据模型级契约。
