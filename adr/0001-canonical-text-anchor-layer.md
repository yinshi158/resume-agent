# 0001. canonical_text 为唯一锚定层，只做机械归一化

状态：已定稿（v0.4，P0）
日期：2026-09-16

## 背景

gate1 的核心交互是"原文 span 高亮联动"，span 锚在哪层文本不定死，整个
M1 是空中楼阁。候选层：PDF 抽取文本层、Markdown 层、独立规范文本层。
另：日期归一化一度被误放进锚定层归一化清单——日期解释是语义判断
（"03/04" 是 3 月 4 日还是 2003 年 4 月？），会错，错误会被烤进锚定层
且 v1 无纠错交互。

## 决定

1. ingest 产出**规范原文层 canonical_text**，入库即不可变，是所有
   span / quote / 高亮联动的唯一锚定载体，偏移 = 其字符偏移。
2. Markdown 只是喂给 LLM 的输入视图，不承载锚点。
3. canonical_text 只做**机械归一化**（NFKC、全角→半角、空白折叠）：
   无损、可逆、无歧义。先归一化再算偏移。
4. 日期归一化下沉到抽取层：结果存结构化字段，歧义走 anomaly
   "日期格式歧义"标记，gate1 以"原始 ↔ 归一化 + 歧义徽标"人工确认。
5. normalize 函数是唯一实现，入库与 quote 校验共用；版本化管理，
   **任何改动 = 全量重入库**；M1 配属性测试（幂等性 + 中文样本偏移
   稳定性快照）。
6. 阅读序以抽取器为准，不回链 PDF 视觉坐标；gate1 提供
   "切换 MinerU 重新解析"逃生门。

分层原则：锚定层永远保真；解释层允许错、可标记、可确认。

## 后果

- 正面：锚定体系可信，quote/span 校验语言无关，误报来源单一（只看
  normalize 一个函数）。
- 负面：normalize 成为全系统最承重的单点，改动代价 = 全量数据迁移，
  必须用版本号和属性测试守住。
- 不可逆性：数据一旦入库，偏移与 normalize 版本永久绑定。
